###Git Commands###

####Setup & Config
1. git --version
2. git config --global user.name "your name"
3. git config --global user.email "you@sample.com"


####Basic Workflow
1. create a folder mkdir <foldername>
2. git init


####Viewing Changes
1. git status
2. git log

####Stage file
1. git add <filename> or git add . 


####Track file
1. git commit -m "commit-message"
